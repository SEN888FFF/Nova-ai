NOVA AI 2.0 — полный исходный проект

ЧТО УЖЕ ЕСТЬ
- Адаптивный неоновый интерфейс для телефона и компьютера
- Главный чат и 7 тематических модулей
- История текущего диалога и сохранение задач/настроек на устройстве
- PWA: можно установить сайт как приложение из поддерживаемого браузера
- Серверный API-маршрут для подключения модели
- Capacitor-конфигурация для упаковки веб-приложения в Android
- GitHub Actions workflow для сборки APK после загрузки проекта в GitHub

ВАЖНО О НАСТОЯЩЕМ ИИ
Сам интерфейс не содержит секретного ключа. Для настоящих ответов нужен сервер
с OPENAI_API_KEY. Не вставляй ключ в HTML, APK, переписку или публичный репозиторий.
API может быть платным. Несовершеннолетнему пользователю настройку аккаунта,
ключа и возможной оплаты должен помогать выполнять родитель/опекун.

ЗАПУСК В СРЕДЕ С NODE.JS
1. Распаковать архив.
2. Установить зависимости: npm install
3. Создать на сервере .env по образцу .env.example и добавить ключ безопасно.
4. Запустить: npm start
5. Открыть адрес сервера в браузере.

ANDROID APK
Автоматическая сборка описана в .github/workflows/android-apk.yml.
Для неё нужно загрузить проект в GitHub и запустить workflow Actions.
Результат debug APK появится в артефактах запуска workflow.
Этот архив — исходный проект, не готовый APK. Сборку APK ещё нужно выполнить
в Android build environment. Подписание release APK для публикации — отдельный шаг.

PWA НА ТЕЛЕФОНЕ
Размести сайт на HTTPS-хостинге. Затем открой его в Chrome Android и выбери
меню браузера → Установить приложение / Добавить на главный экран.
Для работы настоящего ИИ сервер должен быть доступен по HTTPS.
